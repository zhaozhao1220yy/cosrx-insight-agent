Agent Architecture

COSRX 消费者洞察 → 营销策划 Agent

从真实商品评论到可落地营销策划案，5 个环节自动衔接，质检兜底，每个结论可追溯。

输入：真实评论 8,321 条（Kaggle 公开数据集 · Sociolla 印尼电商 · COSRX）

1数据工 Data Cleaner

读原始评论，去重、去噪、规范化，输出干净数据和质量报告。

产出 reviews_clean.csv · data_quality_report.json

2分析师 Analyst

满意度、忠诚度、人群画像、痛点挖掘，再加 LDA 主题模型发现讨论焦点。

产出 insights.json · lda_topics.json

3策划师 Planner

把洞察翻译成营销策划案（调用大模型），产出人群定位、内容选题、活动策划、关键话术。

产出 marketing_plan.md

4质检 QA抓出 8 处过度推断

逐条核查策划案的每个数字能否追溯到原始数据，拦截 AI 的过度推断和幻觉。

产出 qa_report.md

3b修正 Revise

根据质检报告收敛过度推断、修正口径，产出严谨版策划案。

产出 marketing_plan_v2.md

输出：消费者洞察报告 + 严谨版营销策划案（每个数字可追溯到原始评论）

为什么这样设计

  • 每个 Agent 只做一件事，互相独立，出问题能定位到具体环节。
  • 质检单独成环，AI 生成的结论先过一遍事实核查，再交给人工判断。
  • 人只保留 AI 替代不了的营销判断，重复劳动交给流水线。
